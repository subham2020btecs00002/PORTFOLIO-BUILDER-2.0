# 📡 Unified API Reference

All client-facing requests are dispatched through the **API Gateway** ingress facade:
- **Local Development Base URL:** `http://localhost:3001`
- **Production Base URL:** `https://portfolio-api-gateway.onrender.com`

---

## 🔐 Authentication & Headers

| Header | Required | Format / Description |
|---|---|---|
| `Content-Type` | Yes (for JSON endpoints) | `application/json` |
| `Authorization` | Optional / For API calls | `Bearer <access_jwt_token>` (or via HttpOnly cookie `jwt`) |
| `x-correlation-id` | Auto-generated by Gateway | Standard UUID for distributed request tracing |
| `x-internal-secret` | Internal only | Verified by downstream services to reject direct external traffic |
| `x-user-id` | Internal only | Injected by API Gateway into upstream headers upon token validation |

## 1. Authentication Endpoints (`/api/auth`)

### Register
- **Route:** `POST /api/auth/register`
- **Body:**
  ```json
  {
    "email": "user@example.com",
    "password": "Password123!"
  }
  ```
- **Responses:** `201 Created`, `400 Bad Request` (Email already exists).

### Verify Email
- **Route:** `POST /api/auth/verify-email`
- **Body:** `{ "token": "string" }`
- **Responses:** `200 OK`, `400 Bad Request` (Invalid or expired token).

### Login
- **Route:** `POST /api/auth/login`
- **Body:**
  ```json
  {
    "email": "user@example.com",
    "password": "Password123!"
  }
  ```
- **Responses:** `200 OK` (Sets HttpOnly `jwt` and `refreshToken` cookies), `401 Unauthorized`.

### Refresh Session
- **Route:** `POST /api/auth/refresh`
- **Cookies:** Requires valid `refreshToken`
- **Responses:** `200 OK` (Issues new access cookie), `401 Unauthorized`.

### Logout
- **Route:** `POST /api/auth/logout`
- **Responses:** `200 OK` (Clears cookies).

### Current User Profile
- **Route:** `GET /api/auth/me`
- **Auth:** Requires logged-in user
- **Responses:** `200 OK` with user profile object.

## 2. Portfolio Management Endpoints (`/api/portfolio`)

### Fetch Active User's Portfolio
- **Route:** `GET /api/portfolio/me`
- **Auth:** Required
- **Responses:** `200 OK` with portfolio schema, or `404 Not Found` if user has not yet created one.

### Save / Create Portfolio
- **Route:** `POST /api/portfolio`
- **Auth:** Required
- **Body:** Complete or partial portfolio payload (see schema in [Service Portfolio Backend](Service-Portfolio-Backend)).
- **Responses:** `201 Created`.

### Update Portfolio
- **Route:** `PUT /api/portfolio/:id`
- **Auth:** Required
- **Body:** Modified fields.
- **Responses:** `200 OK`.

### Public Portfolio View
- **Route:** `GET /api/portfolio/public/:slug`
- **Auth:** **Public** (No authentication required)
- **Responses:** `200 OK` (increments analytics view counter) or `404 Not Found`.

## 3. AI & Resume Extraction Endpoints

### Parse Resume PDF
- **Route:** `POST /api/portfolio/parse-resume`
- **Auth:** Required
- **Request:** `multipart/form-data` with key `file` containing binary PDF resume.
- **Responses:** `200 OK` returning structured JSON draft:
  ```json
  {
    "personalInfo": { "fullName": "John Doe", "email": "john@doe.com" },
    "skills": [{ "category": "Languages", "skills": ["TypeScript", "Python"] }],
    "experiences": [{ "company": "Tech Corp", "role": "Senior Engineer" }]
  }
  ```

### AI Bullet Point Enhancement
- **Route:** `POST /api/portfolio/enhance-bio`
- **Auth:** Required
- **Body:**
  ```json
  {
    "text": "Created an API gateway",
    "tone": "professional"
  }
  ```
- **Responses:** `200 OK` with `{ "enhanced_text": "..." }`.

### Server-Sent Events Recommendation Stream
- **Route:** `GET /api/portfolio/ai/stream/:userId`
- **Protocol:** `text/event-stream` (Server-Sent Events)
- **Auth:** Required

## 4. Contact & Analytics Endpoints

### Submit Visitor Contact Inquiry
- **Route:** `POST /api/contact/:portfolioId`
- **Auth:** **Public**
- **Body:**
  ```json
  {
    "senderName": "Jane Recruiter",
    "senderEmail": "jane@company.com",
    "subject": "Senior Full Stack Opportunity",
    "message": "Hi, I loved your portfolio! We would love to chat."
  }
  ```
- **Responses:** `201 Created` (dispatches Nodemailer alert to portfolio owner).

### Record Resume Download Event
- **Route:** `POST /api/portfolio/analytics/:slug/download`
- **Auth:** **Public**
- **Responses:** `200 OK`.
