# 📡 Unified API Reference

All client-facing requests are dispatched through the **API Gateway** ingress facade:
- **Local Development Base URL:** `http://localhost:3001`
- **Production Base URL:** `https://portfolio-api-gateway.onrender.com`

---

## 🔐 Authentication & Headers

| Header / Cookie | Required | Format / Description |
|---|---|---|
| `Content-Type` | Yes (for JSON endpoints) | `application/json` (or `multipart/form-data` for file uploads) |
| `Cookie: access_token` | Authenticated routes | Short-lived HttpOnly JWT (15 min validity) |
| `Cookie: refresh_token` | Refresh endpoint | Long-lived HttpOnly JWT (7 day validity) |
| `Authorization` | Optional fallback | `Bearer <access_jwt_token>` (fallback if cookies unavailable) |
| `x-correlation-id` | Auto-generated / Propagated | Distributed tracing UUID generated by Gateway |
| `x-internal-secret` | Internal only | Shared secret injected by Gateway; rejected with `403` if called directly |
| `x-user-id` | Internal only | Decoded MongoDB user ObjectId injected upstream |
| `x-user-role` | Internal only | Decoded role claim (`user` or `admin`) injected upstream |

## 1. Authentication Endpoints (`/api/auth`)

### Register
- **Route:** `POST /api/auth/register`
- **Auth:** Public
- **Body:**
  ```json
  {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "password": "Password123!"
  }
  ```
- **Responses:** `201 Created`, `400 Bad Request` (Email already registered).

### Login
- **Route:** `POST /api/auth/login`
- **Auth:** Public
- **Body:**
  ```json
  {
    "email": "jane@example.com",
    "password": "Password123!"
  }
  ```
- **Responses:** `200 OK` (Sets HttpOnly `access_token` and `refresh_token` cookies), `401 Unauthorized`.

### Refresh Session
- **Route:** `POST /api/auth/refresh`
- **Cookies:** Reads `refresh_token`
- **Responses:** `200 OK` (Sets new `access_token` cookie), `401 Unauthorized`.

### Logout
- **Route:** `POST /api/auth/logout`
- **Auth:** Required
- **Responses:** `200 OK` (Clears authentication cookies).

### Current User Profile
- **Route:** `GET /api/auth/user`
- **Auth:** Required
- **Responses:** `200 OK` with user object (`id`, `name`, `email`, `role`, `username`).

### Update Custom Username Slug
- **Route:** `PATCH /api/auth/username`
- **Auth:** Required
- **Body:** `{ "username": "janedoe" }`
- **Responses:** `200 OK`, `400 Bad Request` (Username taken or invalid format).

### Forgot Password
- **Route:** `POST /api/auth/forgot-password`
- **Auth:** Public
- **Body:** `{ "email": "jane@example.com" }`
- **Responses:** `200 OK` (Dispatches reset email with one-time token via Gmail SMTP).

### Reset Password
- **Route:** `POST /api/auth/reset-password`
- **Auth:** Public
- **Body:**
  ```json
  {
    "token": "example-reset-token",
    "newPassword": "NewStrongPassword123!"
  }
  ```
- **Responses:** `200 OK`, `400 Bad Request` (Token expired or invalid).

## 2. Portfolio Management Endpoints (`/api/portfolio`)

### Fetch Active User's Portfolio
- **Route:** `GET /api/portfolio`
- **Auth:** Required
- **Responses:** `200 OK` with full portfolio document, or `404 Not Found`.

### Check Portfolio Existence
- **Route:** `GET /api/portfolio/exists`
- **Auth:** Required
- **Responses:** `200 OK` returning `{ "exists": true|false }`.

### Save / Create Portfolio
- **Route:** `POST /api/portfolio`
- **Auth:** Required
- **Content-Type:** `multipart/form-data`
- **Body Fields:** JSON portfolio payload (`personalInfo`, `skills`, `experiences`, `projects`, `education`, `themeConfig`), optional binary files `pdf` (max 2MB) and `avatar` (max 2MB).
- **Responses:** `201 Created`.

### Update Portfolio
- **Route:** `PUT /api/portfolio`
- **Auth:** Required
- **Content-Type:** `multipart/form-data`
- **Body Fields:** Modified portfolio fields, optional updated `pdf` and `avatar`.
- **Responses:** `200 OK`.

### Delete Portfolio
- **Route:** `DELETE /api/portfolio`
- **Auth:** Required
- **Responses:** `200 OK` (`{ "message": "Portfolio successfully deleted." }`).

### Public Portfolio View by Username
- **Route:** `GET /api/portfolio/public/by-username/:username`
- **Auth:** **Public**
- **Responses:** `200 OK` (Increments view counter), `404 Not Found`.

### Public Portfolio View by User ID
- **Route:** `GET /api/portfolio/public/:userId`
- **Auth:** **Public**
- **Responses:** `200 OK`, `404 Not Found`.

### Download Resume PDF
- **Route:** `GET /api/portfolio/download/:id`
- **Auth:** **Public**
- **Responses:** `200 OK` with `application/pdf` binary stream.

### Fetch Avatar Image
- **Route:** `GET /api/portfolio/avatar/:id`
- **Auth:** **Public**
- **Responses:** `200 OK` with `image/*` binary stream.

### Fetch Visitor Analytics
- **Route:** `GET /api/portfolio/analytics`
- **Auth:** Required
- **Responses:** `200 OK` returning `{ "views": 142, "downloads": 18, "contacts": 5 }`.

## 3. AI & Resume Extraction Endpoints

### Parse Resume PDF (FastAPI ML Service Proxy)
- **Route:** `POST /api/portfolio/ai/parse-resume`
- **Auth:** Required
- **Content-Type:** `multipart/form-data` with `file: resume.pdf`
- **Rate Limit:** 4 parses/day for regular users; unlimited for admins.
- **Responses:** `200 OK` returning structured JSON draft.

### AI Bullet Point Enhancement
- **Route:** `POST /api/portfolio/ai/enhance`
- **Auth:** Required
- **Body:** `{ "text": "Built a microservices backend with NestJS" }`
- **Responses:** `200 OK` with `{ "enhanced_text": "..." }`.

### Generate AI Portfolio Recommendations
- **Route:** `POST /api/portfolio/ai/recommendations`
- **Auth:** Required
- **Responses:** `200 OK` returning action items and content recommendations.

### Get AI Daily Quota Usage
- **Route:** `GET /api/portfolio/ai/usage`
- **Auth:** Required
- **Responses:** `200 OK` returning `{ "used": 1, "limit": 4, "remaining": 3 }`.

### Clear Recommendations
- **Route:** `DELETE /api/portfolio/ai/recommendations`
- **Auth:** Required
- **Responses:** `200 OK`.

### Server-Sent Events Recommendation Stream
- **Route:** `GET /api/portfolio/ai/stream/:userId`
- **Protocol:** `text/event-stream` (Server-Sent Events)
- **Auth:** Required

## 5. Contact & Analytics Endpoints

- **Body:**

- **Auth:** **Public**
- **Responses:** `200 OK`.

## 6. Administrative Endpoints (`/api/admin`)

*All administrative endpoints require `x-user-role: admin`.*

### System Overview Statistics
- **Route:** `GET /api/admin/stats`
- **Auth:** Admin Only
- **Responses:** `200 OK` with counts for users, portfolios, views, downloads, contacts.

### Search & List Users
- **Route:** `GET /api/admin/users?search=query`
- **Auth:** Admin Only
- **Responses:** `200 OK` with paginated user records and portfolio attachments.

### Update User Role
- **Route:** `PUT /api/admin/users/:userId/role`
- **Auth:** Admin Only
- **Body:** `{ "role": "admin"|"user" }`
- **Responses:** `200 OK`.

### Delete User Account
- **Route:** `DELETE /api/admin/users/:userId`
- **Auth:** Admin Only
- **Responses:** `200 OK`.

### Delete User's Portfolio
- **Route:** `DELETE /api/admin/users/:userId/portfolio`
- **Auth:** Admin Only
- **Responses:** `200 OK`.
