# 🎨 Frontend Architecture, Templates & Intelligence Studio

The **Portfolio Builder 2.0 Frontend** is a modern Single Page Application (SPA) built with **React 18**, **TypeScript**, and **Vite**. It provides an interactive portfolio builder, live real-time previewing, AI resume parser upload flows, an **Interactive AI / DRL Intelligence Dashboard**, and **11 distinct visual themes** for public portfolio display with closed-loop visitor telemetry.

### 1. `usePortfolioForm` Hook
- Centralizes state management across the multi-step portfolio creation wizard.
- Handles debounced auto-saving to local storage and remote backend drafts.
- Performs schema validation for nested sub-documents (dates, URLs, required fields).

### 2. `PortfolioFormShell`
- Multi-step modular accordion interface:
  - **Step 1: Personal Profile:** Name, headline, bio, avatar upload, location, social links.
  - **Step 2: Experience:** Companies, roles, date ranges, and AI-assisted STAR bullet enhancement.
  - **Step 3: Projects:** Titles, descriptions, tech stacks, live links, GitHub repos, and screenshots.
  - **Step 4: Skills:** Grouped by technical categories (Languages, Frameworks, Cloud, Databases).
  - **Step 5: Education & Certifications:** Institutions, degrees, honors, and certificates.
  - **Step 6: Template & Theme Customizer:** Live palette selection, font picking, and slug assignment.

### 3. Animated `ResumeParsingLoader`
- Provides visual feedback when a user uploads a PDF resume.
- Animates through realistic parsing stages: *Extracting Raw Text ➔ Analyzing Work History ➔ Structuring Skills & Projects ➔ Populating Form Fields*.

### 4. Interactive Modals
- `AvatarZoomModal`: Pan and zoom avatar images with responsive touch controls.
- `PdfViewerModal`: In-app PDF reader to preview original uploaded resumes.
- `ProjectSpotlightModal`: Full-screen project showcase with interactive live demo framing.

## 🧠 Interactive AI & DRL Intelligence Dashboard (`/intelligence`)

Accessible from the main navigation, the **Intelligence Studio** (`MlPortfolioPage.tsx`) provides developers with transparent, game-theoretic insight into how recruiters and automated Applicant Tracking Systems evaluate their portfolio:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        AI PORTFOLIO INTELLIGENCE & ATS STUDIO                          │
├──────────────────────────┬──────────────────────────┬──────────────────────────────────┤
│    XGBoost ATS Score     │    SHAP Game Theory      │       Skill Gap Recommender      │
│          88.5/100        │    Feature Impact        │   Based on 470 verified profiles │
│       Grade: A (Top 8%)  │  +6.42 pts Quant Metrics │   • Docker (84% affinity)        │
│  Readability: 72.4 (Good)│  +5.18 pts Skill Spread  │   • Kubernetes (76% affinity)    │
│  Action Verbs: 22% (High)│  -2.15 pts Live Links    │   • PostgreSQL (72% affinity)    │
└──────────────────────────┴──────────────────────────┴──────────────────────────────────┘
```

1. **Predictive XGBoost ATS Score Card:**
   - Displays real-time predicted ATS score (0-100) generated by the in-house gradient-boosted tree regressor ($R^2 = 0.9271$).
   - Shows letter grade (A+, A, B, C, D), Flesch-Kincaid readability index, quantifiable metric density, and STAR action verb ratios.
2. **TreeSHAP Game-Theoretic Feature Attribution Waterfall:**
   - Visualizes positive features (pushing score higher) and negative penalties (dragging score lower) relative to the dataset baseline ($70.83$ points).
   - Generates human-readable explanations (e.g., *"Missing live deployment URLs: -2.15 pts"*).
3. **k-NN Skill Gap Recommendations:**
   - Recommends complementary skills using the 64-dimensional technology co-occurrence incidence matrix computed across 470 real-world engineering resumes.
4. **Contextual Bandit Live Simulator:**
   - Interactive testing laboratory allowing developers to test how different visitor segments (LinkedIn recruiter, GitHub engineer, Mobile vs Desktop) trigger distinct layout actions under the LinUCB policy.

## 🔄 Closed-Loop DRL Telemetry in Public Portfolios (`PublicPortfolio.tsx`)

Public developer portfolios (`/p/:username`) actively optimize layout ordering using contextual multi-armed bandits:

1. **Contextual State Gathering on Mount:**
   - Inspects visitor HTTP referrer (`document.referrer`), device viewport/user-agent (`mobile` vs `desktop`), and local time hour (UTC 0-23).
   - Issues `POST /api/portfolio/public/layout-policy/:username` to fetch the optimal layout action.
2. **Dynamic Section Re-Ordering:**
   - Re-orders portfolio sections in the browser DOM according to the LinUCB decision (e.g., *Experience-First* for LinkedIn mobile recruiters vs. *Projects-First* for GitHub desktop developers).
3. **Visitor Behavior Tracking:**
   - Tracks session dwell time (seconds elapsed on page).
   - Captures engagement triggers: clicking GitHub repository links, clicking "Download Resume", clicking "Contact Me".
4. **Telemetry Beacon Dispatch:**
   - On `beforeunload` or component unmount, dispatches a non-blocking browser beacon:
     ```typescript
     navigator.sendBeacon('/api/portfolio/telemetry', JSON.stringify({
       action_id,
       context_vector,
       dwell_seconds,
       contact_clicked,
       resume_downloaded,
       github_clicked,
       bounce
     }));
     ```
   - Triggers instantaneous Sherman-Morrison rank-1 matrix updates in the DRL engine without blocking page navigation.

## 🎭 The 11 Dynamic Portfolio Templates

The template engine (`TemplateRenderer.tsx`) dynamically mounts themes based on the user's `templateId`:

| # | Template Name | Visual Style | Best For | Key Features |
|---|---|---|---|---|
| **1** | **Minimalist** | Clean Swiss typography, monochrome palette, generous whitespace | Minimalists, UX Designers, Writers | Subtle dividers, high legibility, clean layout |
| **2** | **BentoGrid** | Modern Apple/Linear style modular cards | Full-Stack & Product Engineers | Rounded card grid, hover glow effects, metrics counters |
| **3** | **DevTerminal** | Retro Linux command line terminal interface | Backend, DevOps & Systems Engineers | Interactive CLI prompt (`help`, `cat bio`, `skills`, `projects`, `clear`, `contact`) |
| **4** | **GamifiedRPG** | 8-bit retro gaming / pixel art quest log | Game Devs & Creative Programmers | HP/Mana stat bars, quest-log work experiences, inventory skill grid |
| **5** | **AcademicLaTeX**| Formal scientific paper / ACM publication | Data Scientists, Researchers, ML Engineers | Serif typography, two-column layout, formal abstract, numbered sections |
| **6** | **DarkPro** | High-contrast sleek dark mode with neon accents | Modern Frontend & Software Engineers | Dark charcoal surfaces, neon accent glow, frosted glass cards |
| **7** | **Cyberpunk** | Sci-fi HUD, neon magenta/cyan, scanline effects | Web3, Security & Gaming Developers | Glitch text effects, glowing chips, futuristic accents |
| **8** | **Neobrutalism** | High-saturation, stark black borders, 90s retro | UI/UX Designers & Indie Hackers | Thick 3px black borders, harsh drop shadows, vibrant pastel fills |
| **9** | **ClassicGreen** | Traditional corporate emerald palette | Enterprise & FinTech Developers | Forest green accents, corporate hierarchy, clean tables |
| **10**| **Creative** | Fluid SVG shapes, asymmetric layout | Designers & Creative Technologists | Dynamic hero section, fluid SVG shapes, card carousel |
| **11**| **ResumePrint** | Print-optimized standard CV format | Job applicants requiring PDF export | Strictly single/two page layout, print CSS media queries |
